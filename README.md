# 📻 Радио для Lampa

Плагин радио для [Lampa](https://lampa.mx) — латвийские станции и весь каталог Radio Record прямо в вашем телевизоре. С избранным, поиском по категориям и красивым плеером.

---

## ⚡ Установка

1. Откройте **Lampa** → **Настройки** → **Плагины**
2. Нажмите **Добавить плагин** и вставьте ссылку:

```
https://borjanich.github.io/lamparadio/index.js
```

3. Сохраните и перезапустите приложение

В главном меню слева появится пункт **Радио** 🎵

---

## 🎧 Как пользоваться

### Категории
Сверху четыре вкладки — переключайтесь между ними кнопками влево/вправо:

| Вкладка | Что внутри |
|---------|-----------|
| **Избранное** | Ваши сохранённые станции |
| **Все** | Record + латвийские вместе |
| **Record** | Весь каталог Radio Record (десятки жанров) |
| **Латвия** | Популярные станции Латвии |

> При запуске сразу открывается **Избранное** — если оно не пустое.

### Слушать
- Выберите станцию и нажмите **OK** — начнётся воспроизведение
- Справа покажется обложка станции, название и анимация звука
- Нажмите **OK** ещё раз на той же станции — **пауза**, и снова **OK** — продолжить

### Избранное
Чтобы не искать любимые станции каждый раз:

1. Наведите на станцию
2. **Зажмите OK** (долгое нажатие) — откроется меню
3. Выберите **«В избранное»**

У сохранённых станций появится значок ❤️

**Переставить станции в избранном:**
зажмите **OK** на станции во вкладке «Избранное» → **⬆ Вверх** или **⬇ Вниз**. Так можно собрать удобный порядок — самые слушаемые наверху.

**Убрать из избранного:**
зажмите **OK** → **«Убрать из избранного»**.

## 🎮 Шпаргалка по кнопкам

| Кнопка | Действие |
|--------|----------|
| **OK** | Играть станцию / Пауза |
| **Долгое OK** | Меню: избранное и перемещение |
| **↑ / ↓** | Листать список станций |
| **← / →** | Переключать категории |
| **Назад** | Выйти из плагина |

## ❓ Частые вопросы

**Станция не играет / тишина**
Некоторые станции иногда уходят в офлайн на стороне вещателя. Попробуйте другую — это не проблема плагина.

**Не видно иконку станции**
У части латвийских станций нет логотипа в открытой базе — вместо него показывается значок радио. На звук это не влияет.

**Избранное пропало после переустановки**
Избранное хранится внутри Lampa на устройстве. При полном сбросе приложения оно очищается.

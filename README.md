# Lampa Radio LV

Плагин для [Lampa TV](https://lampa.mx) — радио с латвийскими станциями и Radio Record.

## Установка

1. Открыть Lampa → **Настройки** → **Плагины**
2. Вставить ссылку:

```
https://raw.githubusercontent.com/borjanich/lamparadio/main/index.js
```

3. Сохранить и перезапустить приложение

## Что включено

- **Radio Record** (Record, Deep, Trap) — хардкодом, грузятся мгновенно
- **Латвийские станции** — загружаются с публичного API [radio-browser.info](https://radio-browser.info), отсортированы по популярности

## Источники

- Потоки Radio Record: `radiorecord.hostingradio.ru`
- Латвийские станции: `de1.api.radio-browser.info` (бесплатный публичный API, без ключа)
